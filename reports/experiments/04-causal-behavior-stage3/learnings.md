# Learnings from the intervention experiment

The historical swap rate counts post-edit donor predictions. The stored marginals bound newly acquired donor answers, but the per-pair random and probe changes are unavailable. The literal C-swap test is unevaluable. C-abl does not clear its random-subspace comparison. The class-only results are descriptive and the pairwise questions reuse species. Storing the trial identifiers and both predictions for each edit and comparator makes the targeted transitions directly countable. Expanded random draws were chosen after inspecting the first run. [Intervention audit](../../reviews/2026-11-26-scientific-audit.md#interventions-and-behavior) · [Dated engineering record](https://github.com/BurnyCoder/phylogenetic-geometry-of-tree-of-life-in-llms-mechanistic-interpretability/blob/cc36b9134981497d6006359183261381c25177ac/reports/experiments/04-causal-behavior-stage3/learnings.md)

For a rank test against R sampled subspaces, the smallest attainable p-value is 1/(R+1). The initial draw count limited the corrected test even if the probe ranked first. Variance matching used the training species, and the held-out variance can differ. The comparison with a mean random edit over species answers a different question from the probe’s rank among individual subspaces. [Dated decision to expand](../../preregistration.md#deviations) · [Subspace measurements](../../../results/scientific-verification/subspace-transcript.json)

The first run also used different sentence sets or weighting for baseline and edited off-target losses. The expanded run scored the same neutral tokens through a common loss function. Keeping the readout, target position, recipient ID and comparator together would allow a future analyst to reconstruct individual class transitions.
