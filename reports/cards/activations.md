# Hidden-state readouts for animal species names

The files contain saved float32 readouts. Layout is `<run>/<name_set>/last.npy`, `mean.npy` and `names.txt` where available. Rows follow the accompanying name file. Array dimensions are names × prompts × hidden-state indices × hidden width. Index zero is the embedding output and the final hidden state can include the model's final normalization. `last` selects the last name token and `mean` averages over the name span. [Extraction implementation](https://github.com/BurnyCoder/phylogenetic-geometry-of-tree-of-life-in-llms-mechanistic-interpretability/blob/main/src/phylogeo/extract.py)

Run configurations identify the model, revision field and prompt format. The main Qwen revision is an immutable SHA. Several Pythia settings use release aliases. The archive includes trained and random controls and a sequence of Pythia training checkpoints. Identical distance arrays for some entries are documented in the independent replay. [Configurations](https://github.com/BurnyCoder/phylogenetic-geometry-of-tree-of-life-in-llms-mechanistic-interpretability/blob/main/configs) [Frozen-data calculation](https://github.com/BurnyCoder/phylogenetic-geometry-of-tree-of-life-in-llms-mechanistic-interpretability/blob/main/results/scientific-verification/scale.json)

For example, the primary arrays are under `qwen35_2b/species/` and its random-weight comparison under `qwen35_2b_random/species/`. Other run directories distinguish raw-text prompts (`qwen35_2b_raw`), final and step-zero Pythia controls, and training checkpoints (`pythia14b_step*`). The exact name-set keys include `species_sci`, `species_polysemous`, `conflict`, `heldout_eco`, `days` and `months` where present. Read a slice with `numpy.load(path, mmap_mode="r")` and get the row labels from `names.txt` in the same directory. Wikidata supplies the source names. [Published file tree](https://huggingface.co/datasets/BurnyCoder/phylogenetic-geometry-activations/tree/main) [Wikidata terms](https://www.wikidata.org/wiki/Wikidata:Licensing) [Source data](https://github.com/BurnyCoder/phylogenetic-geometry-of-tree-of-life-in-llms-mechanistic-interpretability/blob/main/data)

Name sets include the primary panel, scientific names, flagged polysemous names, conflict items, held-out habitat species and calendar examples, depending on run. The conflict items share tree IDs with the primary panel. The held-out habitat set has disjoint tree IDs. Published tests concern name representations and the sampled reference tree.
